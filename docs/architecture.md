# 架构与接口约束

## 数据流

```text
采样数据（电压 + 原时间戳）
    ↓ RealtimeEMGDenoiser：校验、分块、分段与预热
    ↓ CausalFilterBank：20–450 Hz因果SOS带通 + 50 Hz IIR梳状器
    ↓ CenteredWavelet：可选的256点db4/SWT中心输出
    → DenoisedBlock：有符号波形、原时间戳、有效状态与延迟观测
    → StreamingFeatures：尾随RMS/包络/频谱
```

## 模块职责

| 模块 | 职责 | 不承担的职责 |
|---|---|---|
| `filters` | 固定DSP参数、输入矩阵校验、每通道滤波状态 | 数据采集、文件读写 |
| `wavelet` | 静息校准、SURE软阈值、真实右上下文缓冲 | 代表性数据判定、会话启用决定 |
| `qualification` / `metrics` | 配对回放、保真/起点评估、校准摘要绑定 | 绕过验收启用候选算法 |
| `core` | 会话配置、因果处理、原时间戳、预热与断流 | 命令行、设备驱动 |
| `features` | 依赖最小只读数据协议的尾随窗口特征 | 修改波形、额外前视 |
| `io` / `replay` | CSV/JSON校验、路径冲突检查、单文件原子替换、回放统计 | 核心算法参数选择 |
| `cli` | 参数解析、服务调用、严格JSON输出和退出码 | 内嵌滤波或CSV处理逻辑 |
| `validation` | 合成数据和本机验证报告 | 真实硬件或临床验收 |

## 关键约束

- 配置在一次会话内只读，切换小波模式必须创建新会话。`reset()`清空信号/时间状态并重新预热；同条件校准可以保留。
- 每次输入先完整校验再改动状态。向前缺样开启新分段；倒退/重复时间被拒绝。
- 输入输出保持同一单位。波形时间戳是采样时刻，不能换成处理完成时间。
- 小波没有校准、验收不通过或摘要不匹配时回到主链，并提供可检查的状态原因。
- 核心缓冲大小有界。有限回放不能补造未来数据，尾部未释放样本计入报告。
- 报告文件为严格JSON；NaN/Infinity写为`null`，不能被当成通过门槛的有效数值。
- 输出CSV及单个JSON文件各自原子替换；多文件输出不是跨文件事务。输入、输出、报告和特征文件不得指向同一文件，包括已有的符号链接或硬链接别名。

## 时间和特征

数据可用延迟、频率相关群延迟、启动收敛、尾随特征的历史区间分别记录。100毫秒是目标整机采样到输出预算；文件回放不能验证采集和传输。

50毫秒RMS、20毫秒RMS包络、1秒频谱均为尾随窗口。频谱使用有符号电压，不从整流波形计算。无足够有效历史时不输出对应特征；零能量频谱的频率不可用。
